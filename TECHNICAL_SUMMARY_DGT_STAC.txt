# ============================================================================
# CAMADA 2: DADOS (Content Level)
# ============================================================================

O QUE É:
- MDT-50cm = Modelo Digital do Terreno com 0.5 m resolução
- Derivado de: LiDAR (aéreo, ICESat-2)
- Coverage: Portugal inteiro
- CRS: EPSG:3763 (ETRS89 / Portugal TM06) — METROS
- Type: GeoTIFF, Float32, banda única (altitude)
- Nodata: -999.0

O QUE NÃO É:
- Não é imagem de satélite (tipo Sentinel-2, ortofotos)
- Não é batimetria (é terrestre, não marinho)
- Não é derivado de SAR (é óptico)


# ============================================================================
# CAMADA 3: USO PRÁTICO (Use Case Level)
# ============================================================================

USE CASE 1: EXTRAÇÃO DE FEATURES ESTÁTICAS
────────────────────────────────────────────

Entrada:
  - Lista de dive sites (lat, lon): ex. [("pedra_sta_eulalia", 37.069, -8.210)]
  - Bbox que cobre todos os sites

Pipeline:
  1. Query STAC → fetch lista de tiles MDT
  2. Download cada tile (50 MB × N tiles)
  3. Mosaic em grid único (EPSG:3763)
  4. Derivar slope = arctan(gradient de altitude)
  5. Derivar aspect = atan2(dz_dx, dz_dy) em graus
  6. Zonal stats num buffer (ex. 1 km raio) à volta de cada site
  7. Export CSV com features por site

Saída:
  site_name, latitude, longitude, slope_mean, slope_p90, aspect_mean, ...
  pedra_sta_eulalia, 37.069, -8.210, 8.5, 15.2, 185.3, ...

Valor:
  - Features estáticas para modelos de visibilidade
  - Correlação com sediment resuspension patterns
  - Não muda com o tempo (data-independent, reutilizável)


USE CASE 2: CONTEXTUALIZAÇÃO TERRA-MAR
─────────────────────────────────────────

Entrada:
  - MDT terrestre (DGT MDT-50cm)
  - Batimetria submarinha (GEBCO 30-m arcsec ou EMODnet)
  - Sentinel-2 multispectral

Stack:
  [altitude, declive, aspect, sentinel_b02, sentinel_b03, ..., profundidade]

Utilidade:
  - Entender dinâmica hidro-sedimentar: terra → costa → submarinho
  - Modelar pluma fluvial com input de slope/drenagem
  - Análise integrada de visibilidade water column + tipo de fundo


USE CASE 3: VISUALIZAÇÃO WEB (Dashboard)
──────────────────────────────────────────

Gerar hillshade a partir de MDT-50cm:
  hillshade = (slope + aspect) → imagem de relevo

Servir como:
  - Camada de background (WMS/COG) no mapa web
  - Contexto visual para divers (entender topografia local)
  - Correlacionar visualmente com pontos de mergulho
